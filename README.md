⚽ Tachkila

Application web pour composer une équipe de football avec le schéma 4-4-2. On ajoute des joueurs à l'effectif, puis on les place sur le terrain.

Fonctionnalités
Formulaire "Ajouter un joueur" (nom complet, poste, numéro de 1 à 99)
Liste de l'effectif avec le nombre de joueurs
Choix de la position de chaque joueur via un menu déroulant
Terrain avec 11 cases (GB, DG, DC, DC, DD, MG, MC, MC, MD, BU, BU)
Légende des couleurs par poste :
Jaune : gardien (GB)
Bleu : défenseur (DEF)
Vert : milieu (MIL)
Rouge : attaquant (ATT)
Case libre (pointillée) ou occupée (grise)
Technologies
HTML5
CSS3 (Grid et Flexbox)
Tailwind CSS (via CDN)
Font Awesome
